    How the fits were made in R

    At 36 equally spaced inputs from −2 to 2, we generated responses with mean 5 + 1.7 sin(1.5x) + 0.3x and independent Gaussian errors with standard deviation 0.45. Each model fits one hidden layer of eight ReLU units with the same initialization seed, 600 warm-start steps and a fixed budget of 60 variational iterations.

    fit <- gltbnn_fit(training, y, hidden = 8L, prior = "GLT", seed = 17L)
units <- gltbnn_shrinkage(fit)
units[, c("unit", "coordinate", "is_bias", "geometric_prior_sd")]
unique(units[c("layer", "geometric_layer_scale", "geometric_tail_shape")])
predict(fit, grid, type = "prediction_interval", level = 0.90,
        draws = 2048L, seed = 23L)

    For original input x∗, the network takes standardized input x∗,std = (x∗ − xtrain)/sx. For a draw of the weights 𝒲, the mean in the original response units is μ𝒲(x∗) = ytrain + sy f𝒲(x∗,std). Both means and standard deviations come from the training data.

    On the standardized fitting scale, σ² is the Gaussian noise variance and σ²(λk1,j)² is the conditional prior variance of a coefficient entering unit k. On the original response scale, a new observation Y∗ has conditional mean μ𝒲(x∗) and conditional variance sy²σ² given the input, weights and noise variance.

    These fits use the paper’s default Jeffreys prior with density proportional to 1/σ². For the supplement’s proper inverse-gamma option, supply positive shape and scale through noise_prior, for example c(shape = 2, scale = 1), on the standardized variance scale.

    At each of 81 inputs, the line averages 2,048 draws of the regression function. The selected band uses the 5th and 95th percentiles of its draws. All three fits use the same bar scale. The layer scale and the GLT tail shape each repeat for all coefficients in their layer. The R example selects one copy of each layer’s summaries.

    Inspect the fitted objective and its Monte Carlo standard error in fit$engine$trace. To check sensitivity to the iteration budget, refit with the same seed and control = list(outer = 120L).
