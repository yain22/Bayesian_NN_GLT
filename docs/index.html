R package / gltbnn

Bayesian neural networks with shrinkage priors

Model continuous, binary, or categorical outcomes with shrinkage on individual hidden weights and biases. Explore how a fitted network predicts timber volume, distinguishes two diagnoses, or assigns probabilities to handwritten digits.

Installation

Download the source package from the GitHub release. Run the code in R 4.1 or later and select the downloaded .tar.gz file.

R console
install.packages(file.choose(), repos = NULL, type = "source")
library(gltbnn)

Fit a regression network

Predict black cherry timber volume from trunk diameter (the Girth column) and height. Set aside three trees, then fit a GLT network with four neurons in one hidden layer.

This example gives the standardized observation variance a proper inverse-gamma prior. predict() estimates mean volume. A prediction interval also includes variation among individual trees with the same measurements.

gltbnn_shrinkage(fit) reports the fitted scale of each hidden weight and bias. The R reference manual gives the equations, arguments, and return values.

R console
x <- trees[c("Girth", "Height")]
holdout <- c(4, 14, 24)

fit <- gltbnn_fit(
  x[-holdout, ], trees$Volume[-holdout],
  hidden = 4L, prior = "GLT", seed = 7L,
  noise_prior = c(shape = 2, scale = 1)
)
predict(fit, x[holdout, ])
predict(fit, x[holdout, ], type = "prediction_interval")

For the first held-out tree, the fitted mean volume is 17.60 cubic feet and the 95% variational prediction interval is 7.05 to 28.63 cubic feet.
