Install the R package

Download the source package from the GitHub release. In R 4.1 or later, run these commands and select the downloaded .tar.gz file.

R console
install.packages(file.choose(), repos = NULL, type = "source")
library(gltbnn)

Fit a regression network

Predict black cherry timber volume from trunk diameter (Girth) and height. Hold out three trees and fit a GLT network with four units in one hidden layer. Here the standardized observation variance has a proper inverse-gamma prior.

The first prediction estimates mean volume. The interval includes variation among individual trees with the same measurements. Use gltbnn_shrinkage(fit) to inspect the scale of each hidden weight and bias.

R reference manual (PDF)

R console
x <- trees[c("Girth", "Height")]
holdout <- c(4, 14, 24)

fit <- gltbnn_fit(
  x[-holdout, ], trees$Volume[-holdout],
  hidden = 4L, prior = "GLT", seed = 7L,
  noise_prior = c(shape = 2, scale = 1)
)
predict(fit, x[holdout, ])
predict(fit, x[holdout, ], type = "prediction_interval")

For the first held-out tree, the fitted mean volume is 17.60 cubic feet and the 95% variational prediction interval is 7.05 to 28.63 cubic feet.
