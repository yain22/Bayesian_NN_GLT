R package / gltbnn

Bayesian neural networks with grouped shrinkage

Fit a Bayesian regression network with a common scale per hidden layer, a grouped horseshoe prior, or a learned tail shape. Inspect the fitted scales and compute variational intervals for a mean response or a new observation.

Installation

Install the package from GitHub in R 4.1 or later. If you need the installer, run install.packages("remotes") once.

R console
remotes::install_github("yain22/Bayesian_NN_GLT")
library(gltbnn)

Fit your first model

Predict black cherry timber volume from trunk diameter (the Girth column) and height. Set aside three trees, then fit a GLT network with four neurons in one hidden layer.

This example gives the standardized observation variance a proper inverse-gamma prior. predict() estimates mean volume. A prediction interval also includes variation among individual trees with the same measurements.

gltbnn_shrinkage(fit) reports the fitted scale summaries for each hidden unit. The R reference manual gives the equations, arguments, and return values.

R console
x <- trees[c("Girth", "Height")]
holdout <- c(4, 14, 24)

fit <- gltbnn_fit(
  x[-holdout, ], trees$Volume[-holdout],
  hidden = 4L, prior = "GLT", seed = 7L,
  noise_prior = c(shape = 2, scale = 1)
)
predict(fit, x[holdout, ])
predict(fit, x[holdout, ], type = "prediction_interval")

For the first held-out tree, the estimated mean volume is 14.6 cubic feet and the 95% variational prediction interval is 4.6 to 25.2 cubic feet.
