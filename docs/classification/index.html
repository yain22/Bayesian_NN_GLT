Model and sampling design

We sampled 100 images per digit from the official training split and 30 per digit from the separate test split. The balanced test accuracy gives each digit equal weight. The gallery displays the original 28 × 28 pixels. For fitting, we average each 2 × 2 block to obtain 196 predictors and standardize using the training images.

A GLT network with one hidden layer of 20 units uses outcome = "categorical". Its nine free scores are log odds relative to digit 9, whose score is zero. At each weight draw, the probability of digit c is exp(ηc)/∑j exp(ηj). We average 128 draws. Test log loss is the mean negative log probability assigned to the recorded digit.

Model and sampling design

We reserved about one fifth of each diagnosis group for testing and excluded the record identifier from the predictors. A GLT network with eight units in one hidden layer uses outcome = "binary". The second factor level is malignant. For a network score η, the probability of this class is 1/(1 + exp(−η)). We average 256 draws before applying the threshold.

Log loss is the mean negative log probability of the recorded diagnosis. The binary Brier score is the mean squared difference between the malignant probability and the indicator of malignancy. Lower values are better for both.

Run the examples and find the data

With gltbnn installed, run Rscript mnist.R or Rscript wisconsin.R. Each script retrieves and verifies its source files, fits the model, and prints the held-out results.
