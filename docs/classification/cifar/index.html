How the 3,072 coordinates are ordered

In the raw vector xrawi, red occupies coordinates 1–1,024, green occupies 1,025–2,048, and blue occupies 2,049–3,072. Within each block, read across each row before moving down. With indices starting at one, the selected coordinate is j = 1,024(q − 1) + 32(r − 1) + c.

For photograph i, the input vector xi contains the 3,072 standardized intensities. For coordinate j we subtract its training mean and divide by its training standard deviation. We apply the same transformation to each test image.

In first-layer unit k, input xij multiplies the scalar weight wk1,j. Under GL and GLT, this connection has its own scale λk1,j. Under G, its scale is the shared layer scale τ1. Explore coefficient-specific shrinkage.

What did the network predict?

From a network score to a class probability

The network produces one logit, f𝒲(xi). Applying the inverse-logit gives the probability of dog, coded 1. The remaining probability belongs to cat, coded 0. The photograph is assigned the more probable class, with exact ties assigned to cat.

G, GL and GLT average the dog probability over 256 draws from their fitted variational distributions. Each FNN uses its fitted weights. Dropout is disabled at prediction time.

Reproduce the comparison

At each architecture the six methods start from the same 600-step initialization and use the same training minibatches for the next 600 updates. Each phase makes 60 passes through the training set. Architectures use fully connected ReLU layers and one Bernoulli logit. The test set is scored after fitting.

The replication archive includes the data preparation, frozen fitting code and independent scoring script. The preparation script downloads the CIFAR-10 binary release and verifies its checksum before selecting the two classes. Photographs are from CIFAR-10, compiled by Alex Krizhevsky, Vinod Nair and Geoffrey Hinton. Original dataset and file format · Krizhevsky (2009).
