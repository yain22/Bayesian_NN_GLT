T-shirts and pullovers in Fashion-MNIST

Can a network distinguish a T-shirt or top from a pullover using the intensities in a 28 × 28 image? Select a held-out garment and compare its fitted probabilities across six classifiers.

How an image enters the network

Reading the rows from left to right maps pixel (r, c) to coordinate j = 28(r − 1) + c of the raw vector xrawi. Indices start at one. To obtain the fitted input xi, we center and scale each coordinate using its training mean and standard deviation.

In first-layer unit k, input xij multiplies the scalar weight wk1,j. Under GL and GLT, this connection has its own scale λk1,j. Under G, its scale is the shared layer scale τ1. Explore coefficient-specific shrinkage.

What did the network predict?

From a network score to a class probability

The network produces one logit, f𝒲(xi). Applying the inverse-logit gives the probability of pullover, coded 1 for this analysis. The remaining probability belongs to T-shirt/top, coded 0. We predict the more probable class and assign exact ties to T-shirt/top.

G, GL and GLT average the pullover probability over 256 draws from their fitted variational distributions. Each FNN uses its fitted weights. Dropout is disabled at prediction time.

Reproduce the comparison

At each architecture the six methods start from the same 600-step initialization and use the same training minibatches for the next 600 updates. Each phase makes 50 passes through the training set. Architectures use fully connected ReLU layers and one Bernoulli logit. The test set is scored after fitting.

The replication archive includes the data preparation, frozen fitting code and independent scoring script. The preparation script verifies the original image and label files before selecting the two classes. Fashion-MNIST images are from Zalando Research.
