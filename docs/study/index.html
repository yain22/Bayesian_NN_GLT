Given the scales, a Gaussian weight prior with a smaller standard deviation puts more mass in every interval centered at zero. Each bar summarizes that standard deviation across the fitted scale values. The Gaussian variational distribution for the weight has its own posterior standard deviation.

The fits share their starting weights. Neurons with the same index can learn different features as fitting proceeds.
