How do Bayesian and frequentist networks regularize?

Follow the connection from trunk diameter to one hidden unit in a network predicting timber volume. All six methods start with the same weights and training trees. Choose a frequentist fit and a Bayesian fit to see what each learns, what happens during a training pass, and how it predicts for a new tree.

Bayesian network

Fit a Gaussian distribution for each weight and bias, along with the shrinkage factors.

Why compare a penalty with a prior? With matching scales, an L₁ penalty can be written as the negative log density of a Laplace prior, up to a constant. Minimizing the penalized loss then gives a posterior mode. The Bayesian fits here learn distributions for the weights and shrinkage scales, and use those distributions for prediction.

What the fits have in common

Diameter and height enter a ReLU network with three units in the first hidden layer and two in the second. Every fifth tree in datasets::trees is held out. The remaining 25 trees supply the standardization and the common starting weights, obtained with 600 squared-error updates (seed 7). Each FNN then takes 600 Adam steps. Each BNN attempts ten weight updates per cycle for 60 cycles, alternating with scale updates. These are separate matched fits for this comparison.
