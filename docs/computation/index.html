How the networks are fitted

To predict timber volume, a network learns how strongly to weight trunk diameter and height. Each Bayesian fitting cycle updates the weights, uses their expected squares to learn shrinkage scales, and returns a precision for the next weight update.

Fit the timber example in R

All three examples predict timber volume from trunk diameter (the Girth column) and height in datasets::trees. They share the training split, starting weights and two hidden layers. Every fifth tree is held out for prediction. Install the package, then run the G, GL or GLT script.

Fitting budget and notation

The examples use 600 initialization steps, 60 fitting cycles and the Jeffreys prior on the standardized observation variance. They return predictions in cubic feet. The scale precision Pkl,j in the equations below is 𝔼q[λkl,j−2]. Multiplying by 𝔼q[σ−2] gives the effective precision for a hidden coefficient in Gaussian regression.

To fit a GLT network for 180 cycles, supply the predictor matrix x and response y, and set the cycle budget in control.

gltbnn_fit(x, y, prior = "GLT",
           control = list(outer = 180L, weight_steps = 10L))

Increasing outer extends the run while keeping ten successive weight-update attempts per cycle. The variance and shrinkage factors are still updated once per cycle.

In the supplement, Section S1 derives the shared variational updates. Section S2 gives the G-BNN algorithm, S3 the GL-BNN algorithm and S4 the GLT-BNN algorithm.

These half-Cauchy expansions use random auxiliaries χτ,l for the layer and χr,kl,j for the GL coefficient. In a fitted layer’s R state, $aux stores the G or GL layer auxiliary factor and $nu stores the GL coefficient auxiliary factors. Under GLT, $nu stores the generalized Pareto mixing factors. Within an inverse-gamma factor, a is its shape parameter.

G-BNN

One scale per hidden layer

The layer size fixes the half-Cauchy prior scale at 1/Ml, where Ml counts the hidden weights and biases in layer l. The fitted layer scale is random. Its squared-scale update uses the expected square of every coefficient. Their next weight updates use the same scale precision.

λkl,j=τl,Pkl,j=𝔼q(τl−2).
χτ,l~IG(1/2,Ml2),τl2∣χτ,l~IG(1/2,1/χτ,l).

The example returns one row per layer. geometric_layer_scale is the geometric mean of the fitted layer scale, and scale_precision is its expected inverse square.

G.RDownload R script
library(gltbnn)
x <- datasets::trees[c("Girth", "Height")]
y <- datasets::trees$Volume
test <- seq(5L, nrow(x), by = 5L)
fit <- gltbnn_fit(x[-test, ], y[-test], hidden = c(3L, 2L),
                  prior = "G", seed = 31L)
scales <- gltbnn_shrinkage(fit)
unique(scales[c("layer", "geometric_layer_scale", "scale_precision")])
predict(fit, x[test, ], type = "mean", draws = 256L, seed = 32L)

GL-BNN

One local multiplier per coefficient

Each hidden weight and bias has its own half-Cauchy multiplier. A fitting cycle updates each squared multiplier and its auxiliary from that coefficient’s expected square, then updates the shared layer scale and its auxiliary. The layer scale and individual multipliers have independent variational factors. Their products share the same fitted layer scale, so the derived coefficient scales in a layer can be dependent under q. The fitted weights and biases have independent Gaussian factors.

λkl,j=τlrkl,j,rkl,j~C+(0,1).
Pkl,j=𝔼q(τl−2)𝔼q(rkl,j−2).
χr,kl,j~IG(1/2,1),rkl,j2∣χr,kl,j~IG(1/2,1/χr,kl,j).

For the first hidden unit the example displays the diameter weight, height weight and bias in that order. Each has its own scale precision. geometric_prior_sd is the geometric mean of its conditional prior standard deviation on the standardized scale.

GL.RDownload R script
library(gltbnn)
x <- datasets::trees[c("Girth", "Height")]
y <- datasets::trees$Volume
test <- seq(5L, nrow(x), by = 5L)
fit <- gltbnn_fit(x[-test, ], y[-test], hidden = c(3L, 2L),
                  prior = "GL", seed = 31L)
scales <- gltbnn_shrinkage(fit)
subset(scales, layer == 1 & unit == 1,
       select = c(coordinate, is_bias, scale_precision, geometric_prior_sd))
predict(fit, x[test, ], type = "mean", draws = 256L, seed = 32L)

GLT-BNN

A learned tail shape in each layer

Each scalar coefficient scale follows a generalized Pareto law given the layer scale and tail shape. In the fitted approximation each coefficient scale has its own independent variational factor, separate from the layer-scale and tail-shape factors. A fitting cycle updates the individual scales, the layer scale, the coefficient auxiliaries and finally the tail shape. One-dimensional quadrature supplies the local-scale and tail-shape moments.

λkl,j∣τl,ξl~GPD(τl,ξl),
Pkl,j=𝔼q(λkl,j−2).

The first summary gives the geometric means of the layer scale and tail shape. The second shows the precision of each incoming weight and bias of the first hidden unit.

GLT.RDownload R script
library(gltbnn)
x <- datasets::trees[c("Girth", "Height")]
y <- datasets::trees$Volume
test <- seq(5L, nrow(x), by = 5L)
fit <- gltbnn_fit(x[-test, ], y[-test], hidden = c(3L, 2L),
                  prior = "GLT", seed = 31L)
scales <- gltbnn_shrinkage(fit)
unique(scales[c("layer", "geometric_layer_scale", "geometric_tail_shape")])
subset(scales, layer == 1 & unit == 1,
       select = c(coordinate, is_bias, scale_precision))
predict(fit, x[test, ], type = "mean", draws = 256L, seed = 32L)
