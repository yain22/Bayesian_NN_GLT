Each matched start launches a separate full fit under each prior. All ten starts are available in the selector. Cycle 0 follows 600 updates of an unpenalized network, which initializes the weight means. Within each cycle, the optimizer makes ten successive attempts to update the weight means and log standard deviations, starting each attempt from the current fit. It then updates the variance and shrinkage factors. Monitoring uses the full training data and the same 32 antithetic pairs of standard-normal perturbations throughout each fit. The resulting weight draws change as the fitted means and standard deviations change. The run stops at its prespecified budget of 60 cycles.

G uses global shrinkage, GL adds coefficient-specific scales, and GLT estimates a tail shape for each hidden layer. Read each curve as progress within a fit. The study compares predictive performance on held-out data. All 270 monitored traces increased at every recorded cycle.
