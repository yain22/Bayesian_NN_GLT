One variational fitting cycle

What happens to the weight connecting trunk diameter to the first hidden unit when a network learns to predict timber volume? Follow that weight through the first fitting cycle in Figure 8 of the paper. Each value comes from fitting the network to the same 25 black cherry trees.

Prior

Reading the cycle

What are we fitting?

A regression network with a given set of weights predicts one mean volume for each tree. During fitting, we allow each weight and bias to vary. We approximate its posterior distribution by a Gaussian with a fitted mean m and standard deviation s. The scales that determine shrinkage have their own variational factors. Section 3.4 and Figure 7 show this factorization.

All factors contribute to one objective, the evidence lower bound (ELBO). It combines the expected log likelihood, the expected log prior and the entropy of the approximation. Holding the scale factors fixed lets us update the weights. Holding the new weight factors fixed then gives us the information needed to update the scales.

How do the updates fit together?

  1. Update the weights and biases. Draw a standard Gaussian value ε for each coefficient and form w = m + sε. Run the sampled network on the training trees. Backpropagation gives the likelihood gradient. Adam uses it together with the Gaussian prior and entropy gradients to propose updates to m and log s. Backtracking compares each proposal with the current weights using the same draws.
  2. Compute two kinds of moments. For each coefficient, the Gaussian factor gives its expected square exactly, H = m² + s². For the nonlinear network, use fresh weight draws to estimate the expected sum of squared residuals across the training trees. Squaring the error of the mean prediction would miss variation between sampled networks.
  3. Update the observation and output scales. The regression noise update combines the expected residual sum of squares with a sum over hidden coefficients. Each term in that sum is the coefficient’s new H times its current expected inverse squared scale. It appears because the regression prior variance of a hidden coefficient is σ²λ². The output weights have their own shared scale κ. Their expected squares update its squared scale u = κ² and then its auxiliary factor.
  4. Update the hidden scales. G pools expected squares within a layer to update one shared scale. GL updates a local multiplier for each incoming coefficient and a common layer scale. Both priors give inverse-gamma coordinate updates. For GLT, integrate the one-dimensional local-scale density on the log scale, update the layer scale and mixing auxiliaries in closed form, then integrate the log-shape density. Supplement Algorithms S1–S3 give the three sets of updates.
  5. Pass the new precision to the next weight update. For a Gaussian response the effective hidden-weight precision is P = 𝔼[σ⁻²] 𝔼[λ⁻²]. With these factors held fixed, the coefficient’s contribution to the expected log prior includes −P(m² + s²)/2. A larger P pulls its mean more strongly toward zero in the next weight block. For binary and categorical responses, the likelihood supplies class probabilities and the corresponding precision is simply 𝔼[λ⁻²].

For example, after the first GLT weight block the diameter weight has mean 0.01650 and standard deviation 0.01030. Its expected square is 0.0003783. The variance update gives a noise precision of 1.242, and the local-scale integral gives an inverse moment of 621.1. Their product, about 771.1 using unrounded values, will enter the next weight block. The mean measured above was fitted using the starting precision of 3.909.

Reproduce the numbers

The fits use datasets::trees. Every fifth tree is held out. The other 25 determine the input and response standardization and the common starting weights. The network has two hidden layers with three and two units. The selected connection receives standardized diameter (the Girth column). Its coefficient is on the fitted network scale.

To inspect the selected coefficient after one cycle in R, run

trees_train <- datasets::trees[-seq(5, 31, by = 5), ]
fit <- gltbnn::gltbnn_fit(
  trees_train[c("Girth", "Height")], trees_train$Volume,
  hidden = c(3L, 2L), prior = "GLT", seed = 31L,
  control = list(outer = 1L)
)
subset(gltbnn::gltbnn_shrinkage(fit),
       layer == 1 & unit == 1 & coordinate == 1)

The scale_precision column reports the local inverse moment (621.1 here). To reproduce the intermediate values for all three priors, run the following from the repository root with R and jsonlite installed.

Rscript tools/generate-trees-cycle.R
