Prior on the observation variance

The study uses p(σ2)∝1/σ2 on the standardized response scale. Posterior propriety holds for almost every response direction under the paper’s conditions. For a given data set, a finite variational fit alone cannot establish propriety. Fitted scales · Model comparison

Pruning unit 2 in layer 1

Ghosh, Yao and Doshi-Velez give the 4 coefficients entering one hidden unit a common local scale. Our GL-BNN assigns each of those coefficients its own local scale. In their notation τ21 is the unit’s local scale and υ1 is the shared layer scale. Their post-fitting rule removes unit 2 if

Prq(τ21υ1<δ)>p0.

Here q is their fitted variational distribution, δ=10−3, and p0=0.9. In the grouped-horseshoe example, move the hypothetical fitted probability across the threshold.

For our models, Prq(σλ21,1<ϵ) summarizes mass near a small conditional weight SD. All 4 units remain in layer 1 of the fitted architecture. ReLU homogeneity allows an outgoing weight to compensate for a rescaling of the incoming weights and bias.

Unordered categorical outcomes

The second response level is the event Yi=1. One affine output gives its log odds. The logistic function converts this value into the Bernoulli event probability.

f𝒲(𝐱i)=𝐯T𝐡~2(𝐱i),
pi=11+exp{−f𝒲(𝐱i)}.

For ten classes the same final activations feed nine free output vectors 𝐯c. Each logit gives the log odds of class c relative to class 10. Softmax converts all ten logits into probabilities that sum to one.

ηic=𝐯cT𝐡~2(𝐱i)(c<10),ηi,10=0.
pic=exp(ηic)∑m=110exp(ηim).

Shrinkage, fitting and prediction

The augmented vector 𝐡~2(𝐱i) contains the eight final activations and a constant 1 for the bias. In classification each hidden weight or bias has conditional prior

wkl,j∣λkl,j~𝒩(0,λkl,j2).

G sets λkl,j=τl across a layer. GL and GLT give each coefficient its own scale. The class probabilities determine the response variance, so the hidden-weight precision in fitting is Eq(λkl,j−2).

The nine output coefficients, including the bias, share a scale κ.

𝐯∣κ~𝒩(0,κ2𝐈9),κ~C+(0,5).

The observed label contributes yilogpi+(1−yi)log(1−pi) to the log likelihood.

For C unordered classes, use C−1 free readout vectors and fix ηiC=0. Here the nine free vectors are conditionally independent given a common κ. Each contains eight weights and a bias, giving 81 free coefficients.

𝐯c∣κ~𝒩(0,κ2𝐈9),κ~C+(0,5).

An observation with label yi contributes logpi,yi to the log likelihood.

Variational fitting uses the expected log likelihood. For a fitted prediction, the package computes probabilities at each variational weight draw and averages those probabilities. The interactive bars show one chosen set of weights.
